# Fonts

The site's font stack is **Airbnb Cereal VF**, then **Figtree** (a free, similar font bundled through `next/font`).

Airbnb Cereal is Airbnb's proprietary typeface, so it is not included in this repository. If you hold a licence
for it, save the variable-weight file here as:

    AirbnbCerealVF.woff2

and reload: every page switches to it with no code changes (see the `@font-face` rule in `src/app/globals.css`).
